## ParkControl 改的是 Windows 里哪几个设置

Windows 有个默认行为，CPU 负载低的时候会把一部分核心停泊掉省电。负载突然上来，系统再把这些核心唤醒，唤醒是有延迟的。你感觉到的“莫名其妙的卡一下”，有时候就是这段延迟造成的。Intel 后来在硬件层面专门为这件事做了干预，说明它影响的人群并不小。

ParkControl 做的事很聚焦，把这些藏在电源计划深处的设置翻到台面上，让你直接改。

主界面几个开关：Parking 控制核心停泊的开关，Freq Scaling 控制频率缩放。高级设置里有两个百分比，Parking % 是“必须保持未停泊的核心比例”，设成 100% 就等于彻底关掉停泊；Freq % 是最低频率比例，设成 100% 就不让 CPU 掉到基频以下。想只让 25% 的核心一直在线、其余允许停泊，也是在这个百分比上调。

对 Intel 12 代以后的大小核机器，它还能选停泊策略。Hetero 模式偏省电，Standard 模式偏性能。长短线程调度可以指定长任务往 E 核上放。这部分是 4.1.0.16 版本（2023 年 9 月）加进来的，同一版还修了 12 代以后核心被错误显示为停泊的问题，那个 bug 连任务管理器和资源监视器都会跟着一起显示错。

另外两样东西是附带的。一个是 Bitsum Highest Performance 电源计划，官方说它比 Windows 自带的“高性能”更激进；另一个是 Bitsum Dynamic Boost，用电脑时切到高性能计划，闲置时自动切回省电计划，适合长期开机又不想一直顶着高频的机器。

还有个不起眼但很实用的功能，它能把停泊相关的设置显示在 Windows 自带的电源选项里。以前要改这些得翻注册表，现在点几下就行。

## 三个下单前要知道的缺点

数字商品发货后不退。数码荔枝的购买须知写得很直白，除非当地法律另有要求或适用单独的售后政策，虚拟商品一经发货不予退款。数字商品基本都这样，但对你意味着买错了没法退钱，试用这一步别省。

“永久授权”的解释权在开发商。条款里写明，“终生”“一次购买”“永久更新”这类说法基于开发商提供的信息，后续的更新维护和政策变更由开发商负责，商店不承担退款或补偿。实际影响是，如果哪天 Bitsum 改了授权模式，你手上这枚码的边界由他们说了算。以这类小工具的历史看风险不高，但你得知道自己买的是什么。

功能面窄，更新也慢。它就做核心停泊和频率调节这一件事，选项不多，摸五分钟就摸完了。从公开的更新记录看，最近一次有实质内容的版本是 2023 年 9 月的 4.1.0.16，主要补大小核调度和修显示 bug。工具的需求本身稳定，更新慢不算硬伤，但也别指望它年年加新功能。

效果还因机器而异。有些 CPU 和电源计划的组合本来就不怎么停泊核心，开关按下去没感觉；有些机器上打开高性能计划，风扇声先起来。买之前没法从参数判断，只能试。
